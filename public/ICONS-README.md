# PWA Icons

This app needs the following icon files for PWA functionality:

- `favicon.ico` - Browser favicon
- `icon-192.png` - PWA icon (192x192)
- `icon-512.png` - PWA icon (512x512)

## Creating Icons

You can create these icons using:
1. Online tools like https://realfavicongenerator.net/
2. Design tools like Figma, Photoshop, or Canva
3. Icon generators

## Recommended Icon Design

- Simple, recognizable symbol (e.g., magnifying glass + leaf)
- High contrast colors
- Works well at small sizes
- Represents health/analysis theme

For now, placeholder icons should be added manually or generated during deployment.
